# py-skia-canvas 0.1.4

This macOS release aligns Canvas with ELK, KaTeX, VChart and Mermaid at version 0.1.4. Use native CPython 3.13 on macOS 13 or later with Apple Silicon or Intel.

```sh
python -m pip install --index-url https://pypi.org/simple/ --only-binary=:all: py-skia-canvas==0.1.4
```

For Windows AMD64 and Linux x86_64 with glibc 2.28 or later, install the published `0.1.0a20` wheel. See the [installation guide](https://github.com/py-VisActor/py-skia-canvas/blob/main/docs/ai/INSTALL.en.md).
